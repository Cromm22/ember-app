# Ember

Eat. Move. Watch a little flame grow up with you.

A fitness tracking web app built with Next.js that makes healthy habits fun through a living avatar companion.

## Features

- **Living Avatar**: Your flame companion (Spark, Blaze, Inferno) grows as you progress
- **Calorie Tracking**: Log food with barcode scanning (Open Food Facts + USDA)
- **Exercise Logging**: Quick-add workouts or log manually
- **Water Tracking**: Stay hydrated with visual glass tracker
- **Compete & Share**: Leaderboards and social features

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Local storage for data persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Building

```bash
npm run build
npm start
```
